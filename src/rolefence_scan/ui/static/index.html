rolefence-scan

What can your AI assistant really reach in your database? Five short steps. Nothing leaves this computer.

1. Where is your AI's server?

The address your AI assistant is set up with. It usually ends in /mcp. If a gateway sits in front, give the gateway's address here.

2. Do you have a login token?

Optional. With a token for one role (say, sales) the scanner can check whether that role is shown tools it may not use, and whether the token is accepted at all. Leave empty to skip.

Optional. If you gave a gateway in step 1, this lets the scanner try to go round it.

3. Database connection

Optional. The connection string your MCP server uses to reach MongoDB. With it the scanner can check whether that user can write, run code inside the database, or read other collections. It only reads.

Kept in memory for this run only. Never saved, never sent anywhere.

4. The server's config file

Optional. Drop or paste the MCP Toolbox tools.yaml. The scanner reads how each tool is written: write tools, free-form queries, missing row caps, whole records.

5. Ready to scan

This is what the scanner will check. Nothing is changed on your server or in your database.
